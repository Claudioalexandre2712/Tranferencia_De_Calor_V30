Correlações de Zukauskas

Tabela 7-2 · fator de fileiras na Tabela 7-3
Arranjo em linha
  • $0 \leq Re_D \leq 100$: $Nu_D = 0.9 \, Re_D^{0.4} Pr^{0.36}$
  • $100 \leq Re_D \leq 1000$: $Nu_D = 0.52 \, Re_D^{0.5} Pr^{0.36}$
  • $1000 \leq Re_D \leq 2×10^5$: $Nu_D = 0.27 \, Re_D^{0.63} Pr^{0.36}$
  • $2×10^5 \leq Re_D \leq 2×10^6$: $Nu_D = 0.033 \, Re_D^{0.8} Pr^{0.4}$
Arranjo alternado
  • $0 \leq Re_D \leq 500$: $Nu_D = 1.04 \, Re_D^{0.4} Pr^{0.36}$
  • $500 \leq Re_D \leq 1000$: $Nu_D = 0.71 \, Re_D^{0.5} Pr^{0.36}$
  • $1000 \leq Re_D \leq 2×10^5$: $Nu_D = 0.35 (S_T/S_L)^{0.2} Re_D^{0.6} Pr^{0.36}$
  • $2×10^5 \leq Re_D \leq 2×10^6$: $Nu_D = 0.031 (S_T/S_L)^{0.2} Re_D^{0.8} Pr^{0.4}$

Todas as correlações multiplicadas por $(Pr/Pr_s)^{0.25} \times F_N$
$F_N$ é o fator de correção para número de fileiras (Tabela 7-3)
$Re_D$ baseado na velocidade máxima e válido para $N > 16$ e $0.7 < Pr < 500$

Velocidade máxima no banco de tubos
Arranjo em linha
$$v_{max} = v \frac{S_T}{S_T - D}$$
Arranjo alternado
$$v_{max} = v \frac{S_T}{\min(S_D - D, S_T - D)}$$
onde $S_D = \sqrt{S_L^2 + (S_T/2)^2}$
