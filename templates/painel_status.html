Diretrizes de Operação e Análise Térmica

Critérios de regime permanente e validação experimental
Critério de Regime Permanente

O ensaio atinge o regime permanente quando a variação temporal de todas as temperaturas for inferior a 0,2 °C/min em um intervalo de 5 minutos.

Verificação de Uniformidade

Se ΔT = |T2 - T3| for próximo de zero, a chapa opera sob condição de temperatura superficial constante (T_s ≈ const).

Sincronização com a API

As leituras são transferidas via JSON diretamente para os módulos de Convecção Forçada e Escoamento Externo para cálculo automático do coeficiente h.
